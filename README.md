# Save Soluções

Site institucional em Next.js App Router, JavaScript, Tailwind CSS e Framer Motion.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
npm start
```

Os formulários validam e recebem dados pelos Route Handlers em `app/api`. Para envio real, conecte um provedor de e-mail ou CRM no ponto indicado em `lib/api.js`, usando somente variáveis de ambiente do servidor.
